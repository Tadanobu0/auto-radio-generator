# 書き出しは Mac に完全移行し、Windows の書き出し経路は参照用としてだけ残す

- **選択肢**: Mac に完全移行 / 両機で書き出しを保つ
- **採用**: Mac に完全移行(PM 判断。PM が成功を確信)。Windows の経路は移行が済むまでの参照用で、温存のための作り込みはしない
- **理由**: 017 の BIZ UDPGothic の静止画が見比べで合格した。両機を保つと字体・ffmpeg・依存の差を二重に面倒みることになる
- **捨てた理由**: 両機の維持は手間が倍になり、得るものが少ない
- **注意点・未解決**: budoux==0.8.0 の固定は暫定の措置で、Mac 移行後に見直す
