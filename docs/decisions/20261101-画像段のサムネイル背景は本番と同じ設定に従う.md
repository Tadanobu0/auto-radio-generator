# 画像段(images_only)のサムネイル背景は本番と同じ thumbnail_background_mode に従う

- **選択肢**: 設定に関係なく必ず作る / 本番と同じ `thumbnail_background_mode`(dynamic のときだけ)に従う / `_generate_thumbnail_assets` を流用
- **採用**: dynamic のときだけ、別の関数 `generate_images_only_thumbnail_bg` で `<run>/thumbnail_bg.png` を作る
- **理由**: 本番の実行と同じ設定で同じ動き。本番の値は dynamic なので Mac 側で使える
- **捨てた理由**: 必ず作るは static の意図を無視する / 流用は thumbnail.png とメタデータが要り、既存テストのスタブにも当たる
- **注意点・未解決**: 失敗は警告だけ。Mac 側は thumbnail_bg.png が無ければ静的背景のまま
