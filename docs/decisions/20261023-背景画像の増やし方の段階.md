# 背景画像は「小(プロンプト改善)→ 中(枚数増 + パン)」の順に進める(PM 判断)

- **選択肢**: 小(プロンプトの改善だけ)/ 中(約 90 秒ごとに 1 枚 + パン)/ 大(台本に `segments[].visuals` を足す)
