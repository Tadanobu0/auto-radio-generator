# 章タイトルは「：」で主題/副題に折り、背景の切り替えは章タイトルの時刻に合わせる

- **選択肢**: 「：」を 1 行目の行末に残す / 落とす。時刻のずれは、背景を章タイトルに合わせる / 章タイトルを背景に合わせる
- **採用**: 「：」は行末に残す。背景の境界を次のセグメントの最初の発話(ジングルの後、章タイトルが切り替わる時刻)に置く
- **理由**: 「：」を残せば文字を落とさない既存方針のまま。章タイトルの時刻は YouTube チャプターと同じ値で、こちらを正にすれば 2 つが食い違わない
- **捨てた理由**: 「：」を落とすと元の題と表示が食い違う / 章タイトルを背景側に寄せると、背景の側の計算が冒頭 2 秒と 250ms の間を落としていたので、ずれた値を正にしてしまう
- **注意点・未解決**: drawtext は expansion=none にして「%」を字のまま描く。題に半角の「'」が入ると壊れる問題は以前からあり、未対応
