# 画像だけ先に作る実行は scene_images.json を run の下に置き、segment_id で使い回す

- **選択肢**: 使い回しの対応づけを segment_id / 章と場面の番号 / プロンプトのハッシュ。作り直しの seed を乱数 / 前の seed + N
- **採用**: `<run>/scene_images/NN_<segment_id>.png` と `<run>/scene_images.json` を書き、reuse_images_from はその json を segment_id で読む。作り直しは前の run の seed + regen_seed_offset(不明なら segment_id から決めた値 + N)
- **理由**: segment_id は場面の区切りが同じなら本番と一致する。プロンプトは LLM が毎回変えるのでハッシュでは当たらない。seed を決めておくと、何を作り直したかが result.json で追える
- **捨てた理由**: 番号だけは章の増減でずれる / 乱数の seed は再現できない
- **注意点・未解決**: visuals の無い章は音声なしで文字数から発話時間を見積もって切るので、本番と場面の数が変わりうる(合わない場面は warnings に出して作る)
