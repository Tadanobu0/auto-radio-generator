# 場面の指定がある場面のプロンプトは、作り直し → draw の短い英文の順に落とす

- **選択肢**: draw を決まった英文に組む / LLM に draw を 1 文に訳させる / 最初に失敗した長い出力を切って使う
- **採用**: 1 回作り直す → LLM に focus・draw を 1 文の英語に訳させる → それも LLM が答えないときだけ、退けた出力(置き場所が崩れたものはそのまま、長すぎたものはカンマで切る)。汎用の文は LLM がまったく答えないときだけ
- **理由**: draw は日本語で、LLM 抜きでは英語にできない。訳だけなら短く、暴走しにくい
- **捨てた理由**: 決まった英文の組み立ては日本語を訳せない。長い出力を切るのは、ブリーフの「focus・draw をもとにした英文」より主題がぼやける
- **置き場所のチェック**: 「draw が高い・床から離すのに low / floor になる」「高さの語が機器の大きさになる」の 2 つだけを弾く。語が無いことは弾かない(既存テストの出力「on a wooden shelf」を通すため)
- **注意点・未解決**: LLM が止まっているときは、今も汎用の文になる(warnings には出る)。1 場面の LLM 呼び出しは最大 3 回
