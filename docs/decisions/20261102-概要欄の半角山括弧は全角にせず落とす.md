# タイトル・概要欄の半角 < > は全角に置き換えず落とす

- **選択肢**: 落とす / 全角 ＜ ＞ に置き換える
- **採用**: 落とす(`sanitize_for_youtube`・動画タイトル・アップロード直前の保険)。題が `<16 進>` だけなら「参考文献N(ドメイン)」
- **理由**: 既存の制御文字・URL の処理が「落とす」流儀で、radio_director 側も落としている。両経路の表記がそろう
- **捨てた理由**: 全角は radio_director 経路と表記がずれ、PDF 内部名の残りが目立つ
- **注意点・未解決**: 「A<B」のような比較の記号も消えて「AB」になる
