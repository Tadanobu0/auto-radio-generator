# アップロードしない実行は環境変数 ARG_NO_UPLOAD と skip_upload 引数で切る

- **選択肢**: config.yaml の publishing.enable_upload / user_settings.json に項目を足す / run_workflow_sync の引数だけ / 環境変数 + 引数
- **採用**: 環境変数 `ARG_NO_UPLOAD=1` と `run_workflow_sync(skip_upload=True)` のどちらでも公開を飛ばす。既定は今までどおり
- **理由**: run_remote.py はこのリポジトリに無い。環境変数なら launch.ps1 がプロセスにだけ設定すれば run_remote.py を変えなくても公開が止まり、1 回ごとに切れる
- **捨てた理由**: enable_upload・user_settings.json はファイルを書き換える必要があり、戻し忘れると本番の公開が止まる。user_settings.json には upload の項目が無い
- **注意点・未解決**: result.json に `upload_skipped` 等を書くのは run_remote.py 側(radio_director-018)。環境変数をマシン全体に設定すると本番も公開しなくなる
