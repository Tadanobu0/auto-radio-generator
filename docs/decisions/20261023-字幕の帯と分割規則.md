# 字幕の帯は ASS の描画、分割は重み付き DP、改行は BudouX に規則を足す

- **選択肢**: 帯=BorderStyle 3 / BorderStyle 4 / ASS 描画イベント。分割=貪欲+後処理 / DP。改行=形態素解析を追加 / BudouX+規則
- **採用**: ASS 描画イベント(Layer 0)/ 切れ目の種類に重みを付けた DP / BudouX の文節を行頭禁止語で前に繋げる
- **理由**: 話者ごとの縁の色を残せる / 「、」の後の短い残りを避けられる / 新しい依存(本番への pip install)が要らない
- **捨てた理由**: BorderStyle 3 は縁色と箱色が共用、4 は本番 libass の対応が不明 / 貪欲では読点の位置を選び直せない
- **注意点・未解決**: 見た目(帯の濃さ・縁の色)は次の /render のコマで確認する。詳細は DECISIONS.md
