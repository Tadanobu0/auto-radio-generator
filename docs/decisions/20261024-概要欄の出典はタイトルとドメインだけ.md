# 概要欄の出典は「📄 タイトル(ドメイン名、公開日)」の 1 行にし、URL は二重に落とす

- **選択肢**: 🔗 行だけ消して 3 行構造の残り(タイトル + 空行)を残す / 1 件 1 行に詰める / 出典節ごと消す
- **採用**: 1 件 1 行。公開日は従来どおり残し、ドメインと並べて括弧に入れる。www. は外す。組み立て時と、アップロード直前の両方で `strip_urls` を通し、URL は落として続行
- **理由**: URL が無いと 1 件 1 行で足り、空行で区切る意味が無い。保険を 2 か所に置くと、概要文(radio_director 由来)やフッターに紛れた URL も止まる
- **捨てた理由**: 出典節ごと消すのは出典を示すという目的に反する
- **注意点・未解決**: ドメイン名の文字列自体を YouTube がどう扱うかは未確認。旧書式を要求する既存テスト 1 本が落ちる(変えない制約のため PM 判断待ち)。metadata.txt の参考文献も同じ表記にした
