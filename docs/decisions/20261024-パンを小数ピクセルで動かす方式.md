# パンを perspective で小数ピクセルずつ動かし、x264 を veryfast にした

- **選択肢**: crop のまま量だけ増やす / zoompan / 大きく拡大してから crop / perspective(作業幅 1920・960・768)× x264 ultrafast・superfast・veryfast・NVENC
- **採用**: perspective(作業幅 768)+ x264 veryfast。平行移動は画面幅の 12%、ズームは 1.12 ⇔ 1.22 倍、90 秒で全部動く速さ。帯は最大幅を 1480px にして日付を避けた
- **理由**: crop と zoompan は整数ピクセルでしか動かず、ゆっくりだと止まって跳ぶ(実測で 2700 コマ中 2500 コマ停止、2px の跳び)。perspective は毎コマ 0.085px ずつ動く。作業幅 768 で 1 分 7.5 秒・5.6 MB
- **捨てた理由**: 作業幅 1920 は 1 分 19.8 秒 / ultrafast は 32 MB/分(動きの探索が整数ピクセルだけ)/ NVENC は 13 MB/分
- **注意点・未解決**: 009 の PM 判断「ultrafast のまま」のうち preset の部分を変えた。14 分の回でレンダリングは約 +1 分。コマの見た目(ズーム時のぼけ)は未確認
