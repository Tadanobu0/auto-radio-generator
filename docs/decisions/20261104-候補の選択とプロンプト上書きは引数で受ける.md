# 候補の選択(picks)とプロンプトの上書きは run_workflow_sync の引数で受ける

- **選択肢**: 前の run のディレクトリに picks.json を置く / 引数で渡す(dict か JSON ファイルのパス)
- **採用**: 引数 `picks` / `prompt_overrides`(dict か JSON ファイルのパス)。候補数は `candidates`(images_only だけ、1〜16)
- **理由**: run_remote.py は run_workflow_sync を直接呼ぶので、Windows の run ディレクトリへファイルを送る手間が無い。前の run を書き換えないので、同じ画像段の run から選び直せる
- **捨てた理由**: run ディレクトリに置く形は送り込みが要り、置き忘れ・前回の残りに黙って従う
- **注意点・未解決**: プロンプトの上書きは作る場面(regen_scenes・使い回しの無い場面)にだけ効く。使い回した場面の上書きは warnings に出す
