# サムネイル背景のプロンプトは構図をコードで固定し、LLM は場所・具体物・無地の面だけ書く

- **選択肢**: 旧メソッドの指示文を書き換える / 新メソッドで構図を固定し LLM は 3 行だけ / 全文 LLM に書かせて検査だけする
- **採用**: 新メソッド `generate_thumbnail_scene_prompt`(build_prompt から呼ぶ)。正面・具体物は右 3 分の 1・左 3 分の 2 は無地の面・人と文字なし、を固定
- **理由**: 旧指示文が ABSTRACT を求め、日本語の題は英単語抽出で "abstract concept..." に化けていた。合格した上書きは 2 回とも同じ型
- **捨てた理由**: 旧メソッドの書き換えは既存テスト(中身と抽象画のフォールバックを固定)を変えることになる / 全文 LLM 任せは構図が戻る
- **注意点・未解決**: ARG の題は中央寄せ(x 316〜964)。合格例の「左 3 分の 2 余白」に合わせたが、物の左端が題の右端と少し重なりうる。画像での確認はまだ
