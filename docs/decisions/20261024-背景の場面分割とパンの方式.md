# 背景の場面は章の項目の中に持たせ、パンは crop の式で動かす

- **選択肢**: 場面を `timeline.segments` に置き換える / 章の項目の中に `scenes` として持たせる。パンは zoompan / scale + crop
- **採用**: 章の中に `scenes`(章タイトル・チャプター・ジングルは章単位のまま)。パンは 1.05 倍に拡大して crop の x を t の式で動かす(画面幅 5%、左右交互)。映像トラックの NVENC は新設の `video_track_use_gpu`(既定 false)
- **理由**: 章の境界(005)と既存テストを壊さない。crop は `-loop 1` のまま使え軽い。`use_gpu` は本番 true なので流用すると既定が変わる
- **捨てた理由**: 置き換えは音声トラック・ジングルの章単位の前提を崩す。zoompan は重く揺れやすい
- **注意点・未解決**: 1 分の試しでパンはサイズ 1.1 倍・時間ほぼ同じ。既定エンコーダは PM 判断で libx264 ultrafast のまま。crop は整数画素で動くので、90 秒の場面で約 1 秒に 1px ずつ進む(見た目は次の /render で確認)
