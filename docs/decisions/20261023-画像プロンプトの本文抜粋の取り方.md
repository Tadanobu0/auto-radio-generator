# 画像プロンプトに渡す本文は「各論点の最初の引用ターン」を中心に、論点ごとに字数を割り当てて抜く

- **選択肢**: 引用タグ `[src=N]` で論点のターンを探す / key_claim の文と本文を文字列で照合する / 等分だけ
- **採用**: key_claims の出典番号を `ScriptSegment.key_claim_source_idxs` で運び、各番号を最初に引くターンを中心に前後 1 ターンを足す。見つからなければ 4 等分の位置。800 字を論点の数で等分
- **理由**: 引用タグは本文に機械的に付いていて照合が確実。実台本では論点が章の前半に固まっており、窓をまとめて先頭から詰めると結局先頭しか入らなかった(テストで実際に落ちた)
- **捨てた理由**: 文字列照合は言い換えで外れる / 等分だけでは論点の位置を使えない
- **注意点・未解決**: 論点が多い章(7 個以上)は 1 論点あたり 100 字前後で、前後のターンはほぼ入らない。前置きの「no faces」は既存テストが要求するので残した
