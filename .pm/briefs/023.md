# B70 用の設定(config/b70.overlay.yaml)の scheduler を本番と同じ normal にする

## 目的
radio_director-078 で、本番(Windows の ComfyUI)は 768×432・steps 4・cfg 1・euler / normal(scheduler の行が無く ARG の既定 normal)と確かめた。B70 用の overlay は scheduler だけが simple で違う。PM の方針は「送り先だけを替える」なので、比較の前に揃える。

## やること
1. config/b70.overlay.yaml の scheduler を normal にする(sampler_name euler・大きさ・steps・cfg はそのまま)。コメントに理由(本番に合わせた。radio_director-078 の確認結果)を1行
2. B70 用のワークフロー JSON(config/workflow_b70_flux1_schnell_fp8.api.json)の KSampler の scheduler の既定値も normal にするか確かめる。ComfyUIClient が config の値で毎回書き換えるなら変えなくてよい。書き換えない経路があるなら normal に揃える
3. 022 のテストで scheduler simple を期待している箇所があれば、overlay に合わせて直す(既定の euler / normal の期待はそのまま)
4. README の B70 の節の値を合わせる

## 制約
- 既定(overlay を渡さない Windows の動き)は変えない
- B70・Windows には接続しない

## 報告
- 変更の差分
- テストの結果(このジョブで流せなければ、その旨。PM が Mac で流す)
