# YouTube の概要欄から出典の生 URL を外す(動画削除の再発防止)

## 背景
2026-10-23 の HDD の回(radio_20261023_100400)が、概要欄の外部リンク `https://faultnote.com/learn/comparisons/hdd-workload-rate-mttf-afr-spec-reading-before-buying/` を理由に YouTube から削除された(「ヌードや性的なコンテンツ」ポリシー。リンク先ドメインが YouTube 側でそう分類されている)。チャンネルには事前警告が付き、次に同じことが起きると違反警告(1 週間アップロード停止)になる。概要欄は素材の出典 URL を並べる作りで、周辺(tier B)の無名サイトのリンクがそのまま載っていた。

## やること
1. 概要欄(YouTube の description)がどこで組み立てられているかを特定する(このリポジトリか、radio_director の verified_script.json 由来か)。
2. 出典の列挙を「タイトル(ドメイン名)」の形にし、URL(`http://` `https://` で始まる文字列)を概要欄に一切載せないようにする。章ごとのタイムスタンプなど他の内容は変えない。
3. 概要欄に URL が含まれないことを確かめるテストを足す(既存の実台本 fixture で)。アップロード直前にも URL が無いことを検査し、あれば落として(載せずに)続行する保険を入れる。
4. 既存の YouTube 動画の概要欄への遡及は行わない(PM が手で対応)。

## 確認の方法
- `~/cc-bridge/bin/arg-remote sync` → `~/cc-bridge/bin/arg-remote test -q`(Bash の timeout 3600000)。レンダリング・アップロードはしない。

## 制約
- 既存テストは変えない。pip install・本番ツリー操作なし。
- 組み立てが radio_director 側だった場合は、変更せずにその旨と変更案を報告して止まる。
- 要判断事項は無ければ「- なし」。
