# 画像段(--images-only)でサムネイル背景も作る

## 背景
- 書き出しは Mac(arg-render)に移った。Windows は `--images-only` で場面画像を作るだけ。
- 今の `--images-only` は `thumbnail_bg.png` を作らないため、Mac の本番ではサムネイルが常に静的背景になる(radio_director 側は、画像段の出力に `thumbnail_bg.png` があれば写して `--thumbnail-bg` で渡す所まで実装済み)。

## やること
1. `--images-only` の実行で、場面画像と同じ run_dir に `thumbnail_bg.png` も生成して保存する(既存の `workflow.ThumbnailBackgroundGenerator` を使う)。生成に失敗しても場面画像の結果は壊さず、警告にする。
2. 既定の通常実行(書き出しを伴う Windows 経路)の挙動は変えない(追加のみ。既存テストは変更しない)。
3. テストを足す。全テストを流す。
4. 保存先のファイル名と run_dir の位置を報告に書く(radio_director 側が拾う前提)。

## 制約
- .env・client_secret・token・user_settings の値は読まない。
- 既存テスト・コードを壊さない。
