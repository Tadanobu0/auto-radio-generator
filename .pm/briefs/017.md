# フォントの受け口(ARG_FONT_DIR)を足し、BIZ UDPGothic で書き出せるようにする

## 背景
書き出しを Mac に移す(radio_director の docs/mac_render_port_design.md、PM 確定)。Mac には Meiryo が無いので、字幕・章タイトル・日付・サムネイルの 4 か所で `C:/Windows/Fonts/meiryo.ttc` と `Meiryo,105` が固定されているのを、設定で差し替えられるようにする。両機とも BIZ UDPGothic(Regular・Bold、OFL)を使う方針(PM 決定)。差分案は radio_director の docs/mac_render_stage1.md §2、フォントの寸法の調べは docs/mac_render_port_survey.md §6(Meiryo 105 と同じ字の大きさは BIZ UDPGothic で 70 相当。行送りが 1.0em に詰まるので、字幕は 1 行ずつ別の Dialogue にして今の行間を保つ L2 方式が PM 決定)。

## やること
1. 環境変数 `ARG_FONT_DIR`(と必要ならフォント名の設定)を受け、指定されていればそのフォルダの BIZUDPGothic-Regular.ttf / -Bold.ttf を 4 か所すべてで使う。**指定が無ければ今と同じ Meiryo の動き**(既存の本番を変えない)。
2. 字の大きさは「em の px」を正にして、ASS の Fontsize をフォントの寸法から出す(Meiryo で今と同じ見た目になること)。字幕の行間は L2 方式。章タイトル・日付・サムネイルの大きさも同じ考えで揃える。
3. `requirements.txt` の budoux を 0.8.0 に固定する(両機で字幕の改行を同じにするため。Windows は既に 0.8.0)。
4. `test_research_brief_theme_overwrite` の `E:/…/workflow.py` 直読みを `Path(__file__)` からの相対に直す(Mac で落ちるため。テストの意図は変えない)。ほかの既存テストは変えない。新しい挙動にはテストを足す。
5. 確認: このジョブの作業ツリーで、BIZ UDPGothic(/Users/tada/radio-fonts/)と ffmpeg-full(/opt/homebrew/opt/ffmpeg-full/bin/ffmpeg)を使い、字幕・章タイトル・日付・サムネイルの静止画を数枚書き出して、Meiryo の本番のコマ(radio_director の output/renders/20261101_004228/frames/)と並べて見比べられるようにする。

## 制約
- 指定が無いときの既存の挙動を変えない(Append-Only)。秘密情報は読まない。
- 判断が要ること以外は止まらず進める。merge(本番の Windows への配備)は PM の確認後。
