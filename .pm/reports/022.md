## radio_director 側(2 本目)で使う呼び出し方と設定の置き場所
- **呼び出し**(Mac の arg-render の ARG で、画像段を Mac のプロセスで回す):
  ```python
  result = workflow.run_workflow_sync(
      theme=..., external_script_path=<verified_script.json>,
      images_only=True, candidates=9,                     # 選び直しは reuse_images_from / regen_scenes / prompt_overrides(021 と同じ)
      config_overlay="config/b70.overlay.yaml",          # ARG の直下からの相対、または絶対パス
      skip_upload=True,
  )
  ```
  - 本番の書き出し(images_only でない回)は画像を作らない(`reuse_images_from` + `reuse_strict` + `picks`)ので、config_overlay は要らない。渡しても害はない(サムネイル背景を作り直す設定のときだけ B70 に送る)
  - 環境変数で渡すなら `ARG_CONFIG=config/b70.overlay.yaml`。019 と同じく、**引数を勧める**(古い ARG だと TypeError で分かる)。古い ARG かどうかは `"config_overlay" in inspect.signature(workflow.run_workflow_sync).parameters` で見られる。環境変数を使うなら、Windows の予備の経路に引き継がないよう消すこと
- **設定の置き場所**: `config/b70.overlay.yaml`(ARG のリポジトリ内)。width / height を本番に合わせるのは、radio_director 側のブリーフで本番の大きさを確かめた後に、この ARG のファイルを直す(または radio_director 側に同じ形の yaml を持ち、その絶対パスを渡す。どちらかに決めて 1 か所にする)
- **ワークフロー**: `config/workflow_b70_flux1_schnell_fp8.api.json`(写し。正本は b70-box の `comfyui/workflows/flux1-schnell-fp8.api.json`、README の「画像生成」に書いた)
- **Windows の予備**: radio_director のスイッチで今までどおり ssh → launch.ps1 → run_remote.py に回す。そのときは config_overlay を渡さない(Windows の config.yaml のまま)
- **Mac で要るもの**: 画像だけの実行でも前提の確認で VOICEVOX と FFmpeg を見る(`workflow.py` の `check_prerequisites`)。プロンプトの LLM は config.yaml の 192.168.0.86:11435。キャッシュは作業ディレクトリからの相対 `output/.image_cache/` なので、ARG の直下で回す
- **確かめ方**: 処理ログの「画像生成: comfyui http://192.168.0.70:8188 ...」、`generation_metadata.jsonl` の `resolution`、`image_generation_times`(021)。B70 のワークフローが合わないと静止画に落ち、`warnings` に `Workflow structure mismatch` が出る
