## 使い方(Mac 側・Windows 側の設定)
- `ARG_FONT_DIR=/Users/tada/radio-fonts`: そのフォルダの `BIZUDPGothic-Regular.ttf`(必須)と `BIZUDPGothic-Bold.ttf`(任意)を使います。指定が無ければ今の Meiryo のままで、ASS も drawtext もサムネイルも今と同じ文字列になります
- `ARG_FONT_NAME`(任意): ASS の字体名を上書きします。省くとファイルの family 名を使います(Google Fonts 版なら `BIZ UDPGothic`)
- 指定したのに Regular が無いときは `RenderFontError` で止まります。Mac で Meiryo に落ちると豆腐になるので、黙って Meiryo に戻すことはしません
- 見比べの静止画(やること 5)は次で書き出せます。依存(Pillow・budoux・pydub など本番と同じもの)が入った Python で流してください
  ```
  ARG_FONT_DIR=/Users/tada/radio-fonts python3 scripts/render_font_samples.py \
      --ffmpeg /opt/homebrew/opt/ffmpeg-full/bin/ffmpeg \
      --out output/font_samples_017 \
      --reference-dir /Users/tada/radio_director/output/renders/20261101_004228/frames
  ```
  出力は `frame_01〜04.png`(字幕 1 行・2 行と 2 人の話者、右上の日付、章タイトル 1 行・2 行)、`thumbnail.png`、`subtitles.ass`、`compare_sheet.png`(左に本番のコマを名前順、右に今回の画像)、`index.txt` です。本番のコマとは場面の文が違うので、字の大きさ・行の位置・帯・太さを見比べる用です。`ARG_FONT_DIR` を外して Windows で流すと、同じ文で Meiryo 版も作れます

## 字の大きさの決め方
- 正は「em の px」です。libass は ASS の Fontsize を OS/2 の usWinAscent + usWinDescent の高さとして扱うので、Fontsize = em 70px × (winAscent + winDescent) / unitsPerEm で出します。Meiryo は 2171 + 901 = 3072 = 1.5em なので 105 になり、今と同じです。BIZ UDPGothic はファイルから読みます(調べでは 70 前後のはず)
- 字幕の幅の判定(折り返し)も同じ em 70px で、使う字体のファイルで測ります
- 章タイトル(80→72→64→56)・日付(28)・サムネイル(題 180〜40、日付バッジ 45)は、drawtext と Pillow がもともと em の px なので数字は変えていません。章タイトルの幅の判定も使う字体で測ります
- 字幕の L2 方式は字体を替えたときだけです。1 行ずつ別の Dialogue にし、各行の MarginV を「30 + (Meiryo の descent − 字体の descent) + 下からの行数 × 105」にします。これで各行のベースラインが、今の Meiryo 105 を \N でつないだときと同じ高さになります。帯の位置は変えていません。Meiryo のときは今までどおり \N でつなぎます
