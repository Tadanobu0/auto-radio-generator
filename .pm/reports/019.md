### 1. reuse_strict の止まり方(radio_director が読む形)
- **合成の前**: `plan_scene_ids(segments, config, speed_scale)` で場面の segment_id を見積もり(images_only と同じ区切り方)、`reuse_images_from` の `scene_images.json` に画像が無い場面があれば止めます。VOICEVOX も画像生成も呼びません
- **合成の後(見積もりで漏れたとき)**: visuals の無い章は、見積もり(文字数)と実際の音声の長さで場面の数が変わることがあります。そのときは本番の画像の段で `ImageProvider._reused_image` が `ReuseStrictError` を投げ、**画像を 1 枚も作らずに**止まります(合成は済んでいる)。visuals のある章は台本の start_turn で切るので、見積もりと本番が同じです
- 止まったときの `WorkflowResult`: `success=False`、`error_message="reuse_strict: no reusable image in <dir> for N scene(s) (<stage>): <id>, ..."`、`reuse_strict_failed=True`、`reuse_strict_stage="before_synthesis"` か `"render"`、`missing_scene_images=[<segment_id>, ...]`。video_path は None、アップロードもしません
- 余った画像(前の run にあって今回使わなかった画像)では止めません。今までどおり warnings に出るだけです
- result.json の欄: `build_mac_render_result_fields(result)` が次を返します。既存の `build_upload_result_fields` などの欄は変えていません

```json
{
  "reuse_strict": true,
  "reuse_strict_failed": true,
  "reuse_strict_stage": "before_synthesis",
  "missing_scene_images": ["deep_dive_1_scene2"],
  "thumbnail_bg_source": null,
  "reading_fixes_path": null,
  "reading_fixes_applied": 0,
  "upload_error": null
}
```

- 終了コード: ARG 側は `run_workflow_sync` が `WorkflowResult` を返すだけで、終了コードは run_remote.py が決めます。**`result.success` が False なら今の失敗と同じ非ゼロで終える**のを勧めます。reuse_strict で止まったことは `reuse_strict_failed` で見分けられます(専用の終了コードが要るなら radio_director 側で `reuse_strict_failed` を見て決めてください。ARG 側に終了コードの定めはありません)

### 2〜4 の結果の欄
- `thumbnail_bg_source`: 渡した画像のパス(使わなかったら null)
- `reading_fixes_path` / `reading_fixes_applied`: 置き換え表のパスと、合成に渡す文で置き換えた回数
- `upload_error`: アップロードに失敗した理由(例 `YouTubeAuthError: token.json が見つかりません(ブラウザの同意には進みません): <path>`)。アップロードの失敗は今までどおり非致命で、`success=True`・`upload_status="not_uploaded"` のままです

### 読みの置き換え表の形
radio_director の `config/reading_fixes.json` はこのジョブから読めなかったので(worktree の外は読み取りが許可されず)、次のどれでも読めるようにしました。`_` で始まるキーは注記として飛ばします。
- `{"語": "かな", ...}`
- `{"fixes": {...}}` / `{"reading_fixes": {...}}` / `{"replacements": {...}}`
- `[{"word": "語", "reading": "かな"}, ...]`(`from`/`to`、`surface`/`kana`、`src`/`dst` も可。上の包みの中でも可)

値が文字列でない・空の語や読みがあると、合成の前に止めます。置き換えは長い語から 1 回だけで、置き換えた後のかなをもう一度置き換えることはありません。
