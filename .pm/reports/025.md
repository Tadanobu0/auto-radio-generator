## 3. 送り先の決め方
- 8188 は**設定**。コードの既定は `config.yaml` の `comfyui.base_url: http://127.0.0.1:8188`。B70 へは `config/b70.overlay.yaml` の `base_url: "http://192.168.0.70:8188"` を重ねたときだけ
- 替える口:
  - `run_workflow_sync(config_overlay=<yaml>)` か環境変数 `ARG_CONFIG=<yaml>`(引数が勝つ)。yaml は絶対パスでもよいので、**`base_url` だけ違う yaml(例 :8189)を渡せば、コードを変えずに 8189 へ送れる**(その ComfyUI に `flux1-schnell-fp8.safetensors` があり、ワークフローが通ることが前提)
  - Windows 機(4070): radio_director 側の予備のスイッチ(ssh → launch.ps1 → run_remote.py。overlay を渡さず Windows の config.yaml の 127.0.0.1:8188)で今も回せる(022 の PM 判断で予備として残した)。Mac から直接 Windows の ComfyUI へ送る yaml は無い(Windows の ComfyUI が LAN で待ち受けているかは分からない)
- 1 回の実行の中で送り先を切り替える・複数に振り分ける口は無い(1 つの run は 1 つの base_url)

## 4. 送る前の軽いプロンプトと、切れたときのやり直し
- **軽いプロンプト(EmptyImage → PreviewImage)は入れていない**。`ComfyUIClient.check_api_status`(`GET /system_stats`)はあるが、本番の流れからは呼ばれていない(呼ぶのは手動テストのスクリプトだけ)
- **やり直しは無い**。`generate_image` は接続・タイムアウト・HTTP エラー・実行エラーを RuntimeError にして返すだけ。呼び出し側は:
  - 場面: その候補を「失敗」と記録して次の候補へ進む。候補が全部失敗した場面は静止画(assets/backgrounds)に落ち、`warnings` に出る
  - サムネイル背景: 同じく候補ごとに失敗を記録。全部失敗なら warnings だけで、場面画像の結果は返す
  - つまり B70 の ComfyUI が落ちても**止まらず、残りの候補ぶん毎回新しい POST を投げ続ける**(1 枚ごとに接続 10 秒で失敗、またはキューに入れたまま最大 600 秒待つ)。落ちた後に台を替える・待ってからやり直す処理は無い
- 並びは 1 枚ずつ(`ImageProvider._generation_semaphore = Semaphore(1)`、候補は for で順番)。同時に複数は送らない。ComfyUI のキューに 1 件入れ、終わるまで 0.5 秒ごとに見てから次を送る

## b70 の動画の作り溜めとぶつからないための案(決めるのは PM)
1. **時刻で分ける**: radio_director の画像段を回す時間帯を決め、その間は Wan のキューを止める(または逆)。ARG の変更は要らない。ただし radio_director の起動のしかけを先に確かめる必要がある(上の 2)
2. **送り先を替える(設定だけ)**: Wan を載せない台(例 8189)に Flux を常駐させ、`base_url` だけ違う overlay を radio_director から渡す。ARG のコード変更は要らない(yaml を 1 本足すだけ)。B70 の GPU の割り当てを固定できるなら一番簡単
3. **Windows(4070)に戻す**: radio_director の予備のスイッチで今の経路に戻す。B70 にぶつからないが、遅い(B70 は 3.7 倍以上速い)
4. **キューに通す**: b70 側に Flux と Wan を一本のキューで回す仕組みがあるなら、ARG の ComfyUIClient をそこへ送るように変える(base_url を差し替えるだけで済むなら設定で足りる。API が違えば ARG のコード変更が要る)
5. **ARG に備えを足す(コード変更)**: forge-gen の B70 経路と同じく、送る前に軽いプロンプトで台が生きているか確かめる・切れたら待ってやり直す/別の base_url に回す。1〜4 と組み合わせる保険。落ちた台に投げ続ける今の動き(上の 4)はこれで止まる
